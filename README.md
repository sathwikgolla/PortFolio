# Sathwik Golla Portfolio

Clean React portfolio built with Vite, Tailwind CSS, and Framer Motion.

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Update Personal Assets

- Replace `public/Sathwik_Golla_Resume.pdf` with the latest resume.
- Replace `src/assets/profile-placeholder.svg` with a real profile photo and update the import in `src/sections/Hero.jsx`.
- Update `formSubmitEmail` in `src/data/profile.js` from `YOUR_EMAIL_HERE` to your FormSubmit email.
- Update GitHub, LinkedIn, and email links in `src/data/profile.js`.

## Deploy on Vercel

Use the default Vercel settings for Vite:

- Build command: `npm run build`
- Output directory: `dist`
